# The City as System — public source package

This folder contains six original Processing sketches from the course portfolio. Open each `.pde` in Processing. Processing Sound is used in multiple studies; the metro study also uses Processing Video.

`04_City_Four_Lenses` is runnable without its original photograph and generates a procedural fallback. `05_Urban_Groove_Skyline` includes an invented 20-track CSV so its data mapping can be explored without republishing music recordings or the original dataset. Hover audio is absent.

Other sketches rely on photographs, music, video, or a poem image that are not in this public repository. Their source is included for code review, but they may need replacement media to run as originally exhibited. The [portfolio PDF](../assets/City-as-System-final-portfolio.pdf) documents the completed visual results.
